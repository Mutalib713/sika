## Colour

Never hand-picked. Generated by `palette.py --world "<...>"` or `--seed "#hex"`,
or pinned from `tools/palette-picker.html`. A pinned palette is canon and does
not get "improved" mid-project.

**Provenance:** pinned by Mutalib 2026-08-30 from a reference image he supplied — four hexes:
`#A8DCE7`, `#101422`, `#FFFFFF`, `#272B3B`. His four are the anchors and are canon. The gap roles
below were grown from `palette.py --seed "#A8DCE7" --dark` (OKLCH, hue 212°, chroma 0.056), because
four colours cannot carry a money app on their own. **This is pinned. It does not get "improved"
later.**

Tokens are named by the job they do, not by the colour they are. `--surface-raised` survives a
palette change; `--warm-gold-2` does not.

| Token | Value | Source | Used for |
|---|---|---|---|
| `--bg` | `#101422` | **his** | app background |
| `--surface` | `#272B3B` | **his** | cards, list rows, panels |
| `--surface-raised` | `#323749` | derived | sheets, dialogs, the cash-out prompt |
| `--text` | `#FFFFFF` | **his** | amounts, headings, body |
| `--text-muted` | `#9AA1B5` | derived | dates, counterparty, captions |
| `--accent` | `#A8DCE7` | **his** | primary action, money in, selected state |
| `--accent-contrast` | `#101422` | **his** | text *on* accent — never white |
| `--border` | `#333849` | derived | hairlines between rows |
| `--warn` | `#FFC857` | derived | ⚠ reconciliation gap, 80% of budget |
| `--danger` | `#F2777A` | derived | over budget, destructive actions |

### Measured contrast — every pair that carries information

| Pair | Ratio | Needs | |
|---|---|---|---|
| `--text` on `--bg` | 18.34:1 | 4.5 | pass |
| `--text` on `--surface` | 14.05:1 | 4.5 | pass |
| `--text-muted` on `--bg` | 7.11:1 | 4.5 | pass |
| `--text-muted` on `--surface` | 5.44:1 | 4.5 | pass |
| `--accent` on `--bg` | 12.27:1 | 3.0 | pass |
| `--accent` on `--surface` | 9.40:1 | 3.0 | pass |
| `--accent-contrast` on `--accent` | 12.27:1 | 4.5 | pass |
| `--warn` on `--surface` | 9.13:1 | 3.0 | pass |
| `--danger` on `--surface` | 5.15:1 | 3.0 | pass |

### Two hard rules that fall out of the measurements

1. **Never put white text on `--accent`.** `#FFFFFF` on `#A8DCE7` is **1.49:1** — effectively
   invisible. Text on the aqua is always `--accent-contrast` (`#101422`). This is the single
   easiest way to wreck this palette.
2. **`--border` is decorative only.** At 1.57:1 on `--bg` it is a hairline, not information. Any
   border that *means* something — a focused input, a selected chip, a flagged row — must use
   `--text-muted`, `--accent` or `--warn`, never `--border`.

### Money direction is not carried by colour

Deliberate. Colouring every outgoing row red makes an app that is mostly outgoings feel like an
alarm, and red/green is exactly the pair that colour-blind viewers cannot separate.

- **Money out** — plain `--text`, with a `−` sign. The normal case looks normal.
- **Money in** — `--accent`, with a `+`. Rare enough to be worth noticing.
- **`--warn` and `--danger` are reserved for things that need action** — a reconciliation gap, a
  broken budget. Nothing else may use them, or they stop meaning anything.

The sign always carries the meaning. Colour only reinforces it.

**Light mode:** not supported in v1. This is a dark-only palette — `#101422` is the ground, and
inverting it would need a second set of decisions Mutalib has not made. Say so in the app rather
than half-supporting it.

## Accessibility floor

- [ ] Contrast at least 4.5:1 for body text, 3:1 for large text and UI edges
- [ ] Full keyboard path through the core flow, visible focus ring
- [ ] Every image has alt text or is marked decorative
- [ ] Colour is never the only signal for state
- [ ] Screen reader passes on the one path in `app-flow.md` section 2
